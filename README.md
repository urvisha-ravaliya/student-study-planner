# Student Study Planner   

## Project Overview The Student Study Planner is a beginner project idea to help students organise academic tasks in one place.  

## Problem Statement Students may forget assignment deadlines, tests, and revision activities when tasks are recorded in different places.   

## Objectives
- Maintain a list of study tasks.
- Record each task's due date.
- Track task status (Pending or Completed).
- Help students plan their study time.

## Proposed Features
1. Add a study task and its due date.
2. View all tasks in a list.
3. Update a task's status.
4. Identify tasks that are due soon.

## Example 
| Task | Due Date | Status | 
|---|---|---| 
| Complete programming exercise | 10 November 2026 | Pending | 
| Revise database concepts | 12 November 2026 | Pending | 
| Submit statistics assignment | 15 November 2026 | Completed |
